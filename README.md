## O mně

Jsem **Lukáš Kysela / CaseyCZ**. Profesně se dlouhodobě pohybuji v plánování výroby a SAPu; ve vlastních projektech propojuji automatizaci, data, webové technologie, Homebridge, Raspberry Pi a iPhone.

Většina projektů vzniká stejně: něco mi chybí, tak si zkusím vytvořit vlastní řešení a postupně ho vylepšovat tak, aby bylo opravdu použitelné.
