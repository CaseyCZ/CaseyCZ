## About me

I'm **Lukáš Kysela / CaseyCZ**. Professionally, I have long-term experience in production planning and SAP. In my own projects I connect automation, data, web technologies, Homebridge, Raspberry Pi and iPhone.

Most projects start the same way: I need a tool that does not exist exactly the way I want it, so I build my own and keep improving it until it becomes genuinely useful.
